# Security and GDPR

Last updated: 2026-06-18
Owner: Legal and Security

## Hosting

All customer data is hosted in the EU, in AWS eu-central-1 (Frankfurt), with backups in eu-west-1 (Ireland). No candidate data leaves the EU.

## Certifications

ISO 27001 certified since 2024. SOC 2 Type II report available under NDA. Annual penetration test by an external firm; the summary report is available to Enterprise customers on request.

## GDPR

Hirelane acts as a data processor. A Data Processing Agreement is signed as part of the standard contract; no separate negotiation is needed for the standard DPA.

Candidate data retention is configurable per account, with a default of 6 months after a rejection. Candidates receive an automatic email asking for consent to keep their data longer. Consent records are stored and exportable.

Right to erasure requests can be actioned by any admin user and complete within 24 hours across all systems including backups.

## Access and authentication

SSO via SAML 2.0 on Growth and Enterprise. Two-factor authentication is available on all plans and can be enforced account-wide.

Role-based permissions: admin, recruiter, hiring manager, interviewer, read-only. Custom roles on Enterprise.

## Subprocessors

The current subprocessor list is published and customers are notified 30 days before any change. Main subprocessors: AWS (hosting), SendGrid (transactional email), Twilio (SMS notifications, optional and off by default).
